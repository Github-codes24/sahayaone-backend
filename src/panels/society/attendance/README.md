# Society Panel Attendance Marking API Documentation

This directory contains the API implementation for **Society Panel Attendance Operations**, enabling employees, branch managers, and society staff to check daily status, mark punch-in/punch-out with geolocation, view monthly attendance summary reports, and submit leave applications directly within the Society Panel.
